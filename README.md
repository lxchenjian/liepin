# 项目结构
hire-common: 通用工程，工具类、枚举类、异常类、常用属性类、资源类等等

hire-pojo: 所有实体类的管理，pojo、bean、entity、bo、vo、dto 等

hire-api: web接口（应用）的公用依赖

service-user: 用户微服务（7001）

service-company: 企业微服务（6001）
